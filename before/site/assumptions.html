Assumptions and edge cases

No clinic has used this yet. Here is everything we thought about instead.

We can’t show you customers. What we can show you is every assumption this design rests on, every case the Gate actually handles, and what happens when each one fails, with the named test that pins it. 99 tests, all of them in the public repository. If a claim on this page ever stops being true, a test goes red.

Nothing below is aspirational. Anything we have not built says so.

01

What we assume, and why

A job title never establishes authority

Texas delegation law turns on documented evidence, not on what someone is called. An aesthetician is not automatically barred and a nurse is not automatically permitted. The delegation agreement, the protocol, the order and the supervisor decide.

22 TAC Chapter 169 · Texas Occupations Code Ch. 157 · test_aesthetician_without_delegation_is_blocked_but_title_is_reviewed

An unrecognised title is a question, not an answer

If a credential is not mapped to a reviewed pathway, the Gate returns REVIEW, never BLOCKED. The summary says so out loud: “this title alone neither establishes nor disproves delegated authority.” Refusing on an unmapped title would be the software deciding law.

before_v1_gate authority pathway branch

Low confidence outranks an apparent pass

If an extraction that a check depends on came back below the confidence floor, the check cannot report PASS; it routes to a named human, even when the extracted value would have satisfied the rule. A confident-looking wrong value is more dangerous than a missing one.

test_low_confidence_has_precedence_over_apparent_pass

Absence is never validity

A missing delegation id reads as absent, not present. A missing receipt-status record reads UNKNOWN, not valid. Both were real bugs at one point: null != "" is true, which would have inverted the safety default on the delegation check.

test_gate_treats_a_null_delegation_id_as_absent_not_present · test_missing_status_never_reads_as_valid

The rules can change; a past decision cannot

Every decision freezes the canonical rule JSON it used and stores its SHA-256. Re-running an old encounter re-runs it against the snapshot, not against today’s rules. A rule edit needs human review before it can be used by anything.

test_rule_snapshot_is_canonical_and_tamper_evident · test_rule_updates_require_human_review_before_activation

Teach-back measures understanding; a signature measures nothing

Interactive and teach-back interventions outperform ordinary written consent for measured comprehension. So comprehension is scored against a threshold and bound to the same frozen ruleset, a signature alone cannot satisfy it.

AHRQ informed-choice guidance · Systematic review, Med Decis Making 2020

03

When something breaks

A vendor API is down or unconfigured

The system refuses to invent a call it cannot make. Offline it replays typed, integrity-checked cached responses and never touches the network; online it fails loudly rather than fabricating a result.

test_online_mode_refuses_to_invent_unconfigured_vendor_calls · test_online_json_is_frozen_and_offline_never_calls_network

Someone submits real patient data

PHI-shaped input is rejected before it reaches storage, and identifier fields are semantically redacted before anything leaves the vault. This project is synthetic by construction, not by convention.

test_phi_like_input_is_rejected · test_semantic_redaction_removes_identifier_fields_before_egress

A real face is submitted for a baseline

The adapter refuses a face whose provenance is not digest-bound to a known synthetic source, before any transport happens.

test_perfectcorp_adapter_refuses_unproven_face_before_transport

A vendor echoes our credentials back

SerpApi returns the search parameters, key included. Those are redacted before anything is cached, and cached metadata stores digests rather than request values.

test_serpapi_echoed_credentials_are_redacted_before_cache · test_metadata_contains_only_digests_not_request_values

The assembly agent is asked to finish the job

It cannot. Sending for signature defaults to off, the read-back path issues only GETs, and domain registration is unreachable from anything a visitor can click.

test_request_attestation_defaults_to_not_sending · test_collect_attestation_reads_outcome_but_never_produces_it · test_domain_registration_is_never_reachable_from_the_site

A cached response is tampered with

Every seeded cache carries a manifest hash and binary caches are integrity-checked on load. A modified fixture fails rather than quietly changing a verdict.

test_every_seeded_cache_has_a_manifest_hash · test_binary_cache_is_integrity_checked

04

What we have not proven

The honest list, because a judge will ask and we would rather answer first.

  • No clinic has run a real encounter through this. The demand evidence is case law, FDA enforcement and state rulemaking, not customers. The next step is one clinic running one week in shadow mode against their existing paperwork, which tells us whether the refusals are the right refusals.
  • One jurisdiction, one procedure. Texas neurotoxin. Other states are a rule-authoring exercise for a licensed reviewer, not a rewrite, but we have not done it, so we do not claim it.
  • The rules were authored by us, from primary sources. They have not been reviewed by a Texas-licensed clinician or a health lawyer. In production that review is the gate on activation, and the system already requires it.
  • Confidence thresholds are chosen, not calibrated. The 0.80 floor is a defensible starting point, not an empirically tuned one. Calibrating it needs real documents at volume.
  • Sandbox DNS does not resolve publicly, and a TXT record stays mutable by whoever owns the domain. Giving the clinic its own domain removes us from the trust path; it does not make the record notarised.
  • Every clinic, patient, face, licence, lot and document here is synthetic. That is a deliberate constraint, and it is also a limit on what this demonstrates.

Each of the seven checks, the state machine, the audit trail and the receipt are pinned by the 99 tests in the public repository. Run python -m pytest tests -q from a clean clone with the network disabled and you get the same receipt hash we do.
