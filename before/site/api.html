Endpoint reference

Encounter and receipt API

MethodPathPurpose
POST/v1/encounters/demo/evaluateRun the seeded Gate.
GET/v1/encounters/:idState, findings, review tasks, history.
POST/v1/encountersCreate a synthetic encounter from a committed fixture.
POST/v1/encounters/:id/evidenceReplay typed Nutrient extraction.
POST/v1/encounters/:id/remediateAttach documented remediation without DB editing.
POST/v1/encounters/:id/reproduceRerun against the frozen snapshot.
GET/v1/receipts/:idRead a bounded safety receipt.
POST/v1/receipts/verifyRecompute and compare the receipt hash.
GET/v1/rules/TX/NEUROTOXIN_INJECTIONCurrent synthetic-demo ruleset with sources.
POST/v1/webhooksRegister an HMAC-SHA256 signed event target.
POST/v1/rule-proposalsStart the proposed → reviewed → effective workflow.

Safety boundaries

Not for clinical use.

Texas neurotoxin only. Returns a pre-procedure safety determination for human review, never a legal conclusion. The sandbox rejects common real-data patterns.
