Time-Out as a service

One call. The exact facts that failed.

Send one encounter, get back a verdict and the exact facts behind it. This is the same code the demo runs on, not a sandbox copy: you can call it from this page, from curl, or from a clinic’s own booking software. No account, no key, no signup for the demo encounter.

Every example below uses invented data. Nothing here touches a real patient.

The whole lifecycle

Blocked, fixed, cleared. Three calls.

This is the sequence the demo runs, and it works from any client with no credentials. The verdict changes because the evidence changed, not because anything was overridden.

# 1. evaluate the seeded encounter
curl -sX POST $BASE/v1/encounters/demo/evaluate   -H 'Content-Type: application/json' -d '{}'
# -> { "verdict": "BLOCKED", "findings": [ ... 7 checks ... ] }

# 2. attach the missing evidence, as a named actor
curl -sX POST $BASE/v1/encounters/$ID/remediate   -H 'Content-Type: application/json'   -d '{"actor":"your-name","credential_type":"RN", ... }'
# -> 200

# 3. evaluate again against the same frozen ruleset
curl -sX POST $BASE/v1/encounters/$ID/evaluate   -H 'Content-Type: application/json' -d '{}'
# -> { "verdict": "CLEAR" }

Verified end to end over plain HTTP with no key, no token and no cookie. Nobody edits a database at any point: the only way to change a verdict is to attach evidence, and every attempt lands in the append-only audit log.

Instant access

No signup. No key.

Every endpoint works with no credentials at all, and always will. You can still generate a tag if you want one: it labels your calls in the audit log so you can find them again, and it grants nothing.

Safety boundaries

Not for clinical use.

Texas neurotoxin only. Returns a pre-procedure safety determination for human review, never a legal conclusion. The sandbox rejects common real-data patterns.
