Time-Out as a service

One call. The exact facts that failed.

Send one encounter, get back a verdict and the exact facts behind it. This is the same code the demo runs on, not a sandbox copy: you can call it from this page, from curl, or from a clinic’s own booking software. No account, no key, no signup for the demo encounter.

Every example below uses invented data. Nothing here touches a real patient.

  -d '{}'

Endpoint reference

Core encounter API

MethodPathPurpose
POST/v1/encounters/demo/evaluateRun the seeded Gate.
GET/v1/encounters/:idState, findings, review tasks, history.
POST/v1/encountersCreate a synthetic encounter from a committed fixture.
POST/v1/encounters/:id/evidenceReplay typed Nutrient extraction.
POST/v1/encounters/:id/remediateAttach documented remediation without DB editing.
POST/v1/encounters/:id/rerunRerun against the frozen snapshot.

Instant access

No signup. No key.

The public endpoint is hard-limited by its data model to synthetic Texas neurotoxin encounters.

Safety boundaries

Not for clinical use.

Texas neurotoxin only. Returns a pre-procedure safety determination for human review, never a legal conclusion. The sandbox rejects common real-data patterns.
